Hospital Admissions Data Analysis (MySQL)

This project analyzes a hospital admissions dataset from Kaggle (https://www.kaggle.com/datasets/ashishsahani/hospital-admissions-data/data using MySQL). The database was designed from scratch, including schema creation, table structure definition, and CSV data import.

Using SQL, I performed exploratory data analysis on patient demographics, admission types, length of stay, comorbidities, lab values, and outcomes. The analysis includes aggregate functions, date calculations, conditional logic, and grouping operations to generate meaningful clinical insights.

Key SQL skills demonstrated:

Database and schema creation

Data cleaning and validation

Aggregate analysis (COUNT, AVG, SUM, MIN, MAX)

Date functions and length-of-stay calculations

Conditional logic using CASE

Grouping and sorting for trend analysis
